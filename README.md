# Bible Runner

Bible Runner is a [KRunner](https://userbase.kde.org/Plasma/Krunner) plugin (KDE Plasma 6)
that lets you look up Bible verses straight from the launcher. Type a reference such as
`John 3:16`, and press Enter to open it in [YouVersion](https://www.bible.com/); with an API
key configured the runner can also fetch the verse text and copy it to the clipboard.

## Usage

Open KRunner (`Alt+Space`) and type a reference like `John 3:16`, the plugin will offer you to open the passage in your browser or copy the verse text to the clipboard.

## Configuration

Open _System Settings -> Search -> Plugins -> Bible Runner_ (the cog next to the plugin) and set:

- **API key** – get a free one from the [YouVersion Developer Platform](https://platform.youversion.com/platform/apps),
- **Bible version** – picked from the list fetched from the API (cached locally for a month).

## Dependencies

- KDE Plasma 6 / KDE Frameworks 6 (KRunner, KConfig, KI18n, KIO, KCMUtils, KNotifications)
- Qt 6 (Base, Network, Widgets)
- [Boost](https://www.boost.org/) – Boost.Algorithm in the code, Boost.Test for the tests
- [simdjson](https://github.com/simdjson/simdjson) – vendored in `src/lib/` (used to parse the
  book-name tables at compile time)
- Toolchain: CMake ≥ 3.28, Ninja, **clang** (C++20 modules) **and a GCC with C++26 static
  reflection** (`-std=c++26 -freflection`, GCC 16+) for `src/modules/books.cpp`

The easiest way to get exactly this toolchain is [nix](https://nixos.org/) (see below).

## Building and installing

With nix and [just](https://github.com/casey/just):

```bash
just run      # builds with nix, restarts KRunner with the plugin loaded
```

Manually with nix:

```bash
nix-build -E 'with import <nixpkgs> {}; callPackage ./default.nix {}'
```

## Language Support

The book names and abbreviations come from my other project
[obsidian-youversion-linker](https://github.com/jaanonim/obsidian-youversion-linker), which
supports multiple languages. Credits to the authors of the names are given
[there](https://github.com/jaanonim/obsidian-youversion-linker/blob/master/docs/Languages.md).
