# Bible Runner

Bible Runner is plugin for KRunner that allows you to quickly open verse in YouVersion Bible.

## Installation

This project uses [nix](https://nixos.org/) for building and managing dependencies. Make sure you have nix installed on your system.

Using just:

```bash
just run
```

this will build project using nix and install it restarting KRunner.

You can also build and install it manually using:

```bash
nix-build -E 'with import <nixpkgs> {}; callPackage ./default.nix {}'
```

## Language Support

This project is using the books names and abbreviations from my other project [obsidian-youversion-linker](https://github.com/jaanonim/obsidian-youversion-linker) which supports multiple languages. Credits to author of books names and abbreviations are given in that project [here](https://github.com/jaanonim/obsidian-youversion-linker/blob/master/docs/Languages.md).

## Configuration

Configure the plugin in KRunner settings. There you need to set your YouVersion Bible API key. You can get it from [YouVersion Developer Platform](https://platform.youversion.com/platform/apps).
